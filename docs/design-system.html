— design language · v.03 · 2026-07

One neutral ramp, one signal.

This page renders the house UI language from its own tokens — theme/{colors,typography,spacing,motion,icons}.ts — so a rule and its number sit side by side. DESIGN.md is the prose; this is the same system, live.

A theme swaps the signal and nothing else. Try the four temperatures — bands, ink, type, radius and motion never move.

— §01 · bands

Full-bleed, alternating.

The page is a stack of full-bleed bands. Dark is the default; light is a class (.band-light). No component straddles a seam — the crosshairs (┼) above and below mark where one band ends and the next begins. This band is light: it re-applies its own background-color and color, not just its custom properties.

Content is capped at layout.containerMaxWidth (1360px); the band itself is not. The primary action inverts with the band — paper fill here, ink fill on dark.

— §02 · signal

Exactly three jobs, never a fourth.

One neutral ramp per band plus exactly one chromatic signal. It never fills a button and never tints a surface. If you can't name the state a signal pixel represents, it should be neutral.

— §03 · status

Fixed, never themed.

A reader learns these once, so they cannot move — regardless of which signal temperature is active. All four are dot / border / mono-label roles, never a fill, never body text.

liveCurrent, healthy, running. The only status that themes.
degradedSlow, retrying, over budget. #c99a3a — fixed.
incidentDown, failed, destructive. #c9553a — fixed.
idleQueued, paused. Absence of colour is a state.

— §04 · type

One grotesk, one mono meta layer.

Archivo carries everything readable — display, titles, numbers, prose. JetBrains Mono carries the meta layer — labels, data, tags, glyphs, code — never a paragraph. No serif, no italic, anywhere.

— §06 · motion

Motion measures; it never performs.

Nothing bounces, shimmers or spins. One house curve: cubic-bezier(0.2, 0, 0, 1).

Hover — colour/border only, 140ms

Never size, never shadow. Primary buttons dip opacity (0.86) instead of swapping fill — see the primary button above.

Live blink — steps(1, end), 1800ms

hard on/off, not a fade

Respects prefers-reduced-motion — freezes solid instead of blinking.

Disclosure — 220ms, chevron only

What moves →
Only the chevron rotates. No bounce, no height animation trick.

— §11 · contrast gate — measured

Faint ink and the signal are where this can hurt a reader.

PairRatioVerdict
ink on dark17.1:1AAA, any size
muted ink on dark5.7:1AA, body and up
soft ink on dark3.8:1fails AA — sub-copy 19px+
faint ink on dark2.5:1fails AA — metadata only
signal on dark9.1:1AAA, safe as text
ink on light16.1:1AAA, any size
muted ink on light6.5:1AA, body and up
soft ink on light3.0:1fails AA — labels only
faint ink on light1.9:1under the 3:1 floor — decorative only
signal-dim on light3.1:1headings only, 24px/600 up
degraded on light2.3:1under the 3:1 floor — never the dot alone
  • A label that carries an instruction moves up one step of ink — textFaint → textSoft, and → textMuted the moment it carries meaning.
  • Prose never below layout.minTextSize (13px); a mono label never below layout.minLabelSize (9px).
  • Interactive elements are real <button> / <a>, always labeled.
  • Targets: layout.minTouchTarget (44px) minimum; an app row may be layout.rowTarget (36px) as long as its hit area reaches the minimum.

— §12 · banned

Nine things that don't ship.

  • Signal-coloured buttons — the signal never fills a control
  • A second accent hue, or two signals in one view
  • Gradients, glassmorphism, radial glows, grain overlays, animated blobs
  • Serif or italic anywhere; mono paragraphs
  • Shadows on dark bands; shadows on hover; pill buttons
  • Weight-700 headings
  • Icon libraries, illustrations, logo walls, photos beside a quote
  • Spinners, shimmer skeletons, progress bars without a real number
  • Hardcoded hex or magic numbers in components — tokens only

Self-check before calling a screen done:

  • Every colour, size, radius and duration came from a token — no literal.
  • The signal appears in at most one of its three jobs per viewport, and fills nothing.
  • Every heading that takes the signal is two lines, coloured on line two.
  • Each band's components read the band's own map — nothing straddles a seam.
  • Shadows: light bands only. Hover: colour or border only.
  • Every ink/background pair clears §11 for its size.
  • Focus is visible on every interactive element and never removed.
  • Nothing from §12 is present.
